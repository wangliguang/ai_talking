# AI Talking - 智能陪伴小工具

## 📋 项目概述

这是一个为6岁儿童设计的AI智能陪伴工具，通过语音交互提供通识教育内容。

## 🎯 项目需求

### 硬件需求
- ✅ 不需要外壳
- ✅ 尽可能少的接线
- ✅ 尽可能使用拔插方式接线（便于组装和维护）

### 软件需求
- ✅ 大模型可自定义配置
- ✅ 陪伴内容主要针对小学生通识教育
- ✅ 内容过滤：不能出现成人内容
- ✅ 音色可选择
- ✅ 音量可调节

## 🔧 技术栈建议

### 硬件方案建议
1. **方案A（简单）**：树莓派 + USB麦克风 + USB扬声器
   - 优点：接线最少，即插即用
   - 缺点：成本较高

2. **方案B（经济）**：ESP32 + I2S麦克风 + I2S扬声器
   - 优点：成本低，拔插式连接
   - 缺点：需要更多开发工作

### 软件技术栈
- **编程语言**：Python 3.8+
- **语音识别**：Whisper（本地）或云端API
- **语音合成**：edge-tts 或 云端API
- **大模型**：OpenAI API 或 国内大模型API
- **内容过滤**：关键词过滤 + 大模型提示词约束

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置

复制配置文件示例并填入你的配置：

```bash
cp config.example.ini config.ini
```

编辑 `config.ini`，至少需要配置：
- `[llm]` 部分的 `api_key`（大模型API密钥）

### 3. 运行

```bash
python main.py
```

### 4. 使用说明

- 直接输入文本与AI对话
- 输入 `volume <0-100>` 设置音量
- 输入 `voice` 查看可用音色
- 输入 `voice <音色名称>` 设置音色
- 输入 `quit` 或 `exit` 退出

## 📌 注意事项

- 所有内容必须经过安全过滤，确保适合6岁儿童
- 硬件连接尽量使用标准接口（USB、I2S等），便于拔插
- 软件配置应该简单明了，便于后续维护和升级
- 首次运行需要下载Whisper模型（会自动下载）
- 语音播放功能需要系统支持音频输出
